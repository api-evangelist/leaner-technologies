# Leaner Technologies

> 株式会社Leaner Technologies is a Tokyo-based B2B SaaS company (founded 2019-02-22, CEO Yusuke Ohira)
> building the "Leaner" (リーナー) cloud suite for corporate procurement and purchasing departments —
> purchase-to-pay, sourcing/quotation, supplier relationship management, plus procurement BPO and
> consulting. Leaner does NOT publish a public API, developer portal, API reference, or client SDKs.

## Status

- Public API: none found (probed 2026-07-19). No developer portal, no OpenAPI, no API reference,
  no first-party SDKs on npm/PyPI/RubyGems, no `/.well-known/` discovery documents.
- Integration is delivered through partner/EC catalog connections (Amazon Business, MonotaRO)
  and implementation services rather than a self-serve API program.
- github.com/leaner-co-jp contains only forks and internal tooling — no API specs or client libraries.
